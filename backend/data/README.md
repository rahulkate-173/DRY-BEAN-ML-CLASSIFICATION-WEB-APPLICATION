# Dataset for BeanVision AI

Place the official Dry Bean Dataset here:

```
dataset/Dry_Bean_Dataset.xlsx
```

## Source

**UCI Machine Learning Repository — Dry Bean Dataset**
- URL: https://archive.ics.uci.edu/dataset/602/dry+bean
- DOI: https://doi.org/10.1016/j.compag.2020.105507

## Citation

Koklu, M. and Ozkan, I. A. (2020). "Multiclass Classification of Dry Beans
Using Computer Vision and Machine Learning Techniques." *Computers and
Electronics in Agriculture*, 174, 105507.

## Dataset Properties

| Property | Value |
|---|---|
| Records | 13,611 |
| Input features | 16 numerical |
| Target | Class (7 varieties) |
| Missing values | None |
| Format | Excel (.xlsx) |

## Bean Varieties

BARBUNYA, BOMBAY, CALI, DERMASON, HOROZ, SEKER, SIRA

## Download

1. Visit https://archive.ics.uci.edu/dataset/602/dry+bean
2. Click "Download" to get the zip archive.
3. Extract `Dry_Bean_Dataset.xlsx` and place it in this directory.

The file `Dry_Bean_Dataset.xlsx` is already present in this repository's
`dataset/` directory if you cloned from the original project.
